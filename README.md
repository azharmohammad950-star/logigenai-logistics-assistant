# logiMitra — GitHub Pages Interface

This `docs/` folder publishes logiMitra, an AI copilot for logistics professionals, on GitHub Pages.

## Included prototype workflows

- Shipment analysis
- Documentation checks
- Exception management and recovery actions
- Customer email drafting
- The five-part evaluation rubric: factuality, relevance, completeness, assumption control and human verification

The four quick scenarios and deterministic response structures mirror the existing Flask prototype's `build_demo_response()` task logic. GitHub Pages cannot run the Flask `/api/analyze` endpoint, so this static version executes the same demo logic locally in `script.js`.

## Important mode and safety notes

- This static website is **Demo Mode**. Outputs are simulated and are not generated by a live AI model.
- The feature map describes prototype availability, not measured accuracy or productivity.
- Verify carrier schedules, ETAs, rates, customs/legal requirements, contractual SLAs and shipment status with authoritative sources before operational use.
- The document checklist is an operational prompt, not legal or customs advice.
- The existing Flask app remains available at https://logigenai-logistics-assistant.onrender.com.

## Contact details

The contact section includes `hello@logimitra.example` as a reserved demonstration placeholder. It is not a working or monitored mailbox. Replace it with a real address before production use.

## Files

- `index.html` — full logiMitra experience and interactive workspace
- `style.css` — responsive dark-ink, lime and violet visual theme
- `script.js` — local demo response engine and interface behavior
- `.nojekyll` — ensures GitHub Pages serves the static files as expected

## Publish

The repository's GitHub Pages settings should use **Deploy from a branch → `main` → `/docs`**. Commit updates to these files to trigger a new deployment.
